# 候风地动仪 HOUFENG-SEISMOSCOPE — 机构复刻 No.03

张衡候风地动仪(132 AD):都柱倒立摆感震,偏达 6° 触发该方位「八道」机关,
龙口铜丸落入蟾蜍口——「验之以事,合契若神」。外形取王振铎 1951 复原,
机构取冯锐 2005 倒立摆复原思路。B 键查看剖视总图。

## 机构与验算

```
尺寸(复原值):
  铜樽   径 1.44 · 高 1.95(半剖展示内部)
  都柱   倒立摆 · 摆长 1.05 · 枢轴 y=1.15 · 触发角 6°
  八道   自枢轴环向八方的机关道(示意)
  龙首   ×8,八方 45° 等分,口含铜丸 Ø0.096
  蟾蜍   ×8,距 1.96,口高 0.59

事件链(载入期自检):
  地震波 → 都柱向震源倾斜(0.8s 线性爬升)
  → 摆角达 6°(柱顶偏移 1.05×sin6° = 0.11 m,推开八道关)
  → 该方位龙钩释放:下颚张开,铜丸抛物线 0.55s 落入蟾蜍口
  → 蟾蜍弹跳"振声"报警;摆体阻尼回正(τ≈1.2s,3.2s 内静止)
  自检断言:fired = 落丸方位(东=2),其余七方 0 误触发。
```

8 方位定义:k=0 北(−z),顺时针 45° 递增(1 东北、2 东(+x)…4 南(+z))。
